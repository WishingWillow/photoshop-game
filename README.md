Theme Overview
---
Instead of wires/circuits, the game is about connecting houses with paths. The circuit caps on the level boundaries are now the houses of terrestrial/aquatic anthropomorphized animals that should be connected with the proper path type. 

Story
---
The city is trying out a new "modular path-building technique" where we can only build from pre-established path designs. But don't worry! You can treat those designs like layers in an image editor and rotate/mirror/slice them up to meet our needs.
Just remember, altering a path design increases the cost of the project. Luckily, our budget is flexible (we can just dip into the funds we set aside for that new library). Still, it would be nice to minimize costs as much as possible. Good luck, engineer!
